# 未眠 — `/games/unwaking-cn`
Status: LIVE, in games grid

## Text
类型：实验性交互小说（Experimental Interactive Fiction）
职责：主策 / 美术（团队规模：2）
引擎：Unity

未眠 是一个短篇互动小品：你将扮演一缕疲惫的灵魂，在由层叠墨线与漫画分镜构成的黑白世界里游荡，并试着为自己的存在寻找意义。
本项目源自 USC 2025 年 CTIN-534 课程作业。
Itch.io↗ → https://yrannn.itch.io/unwaking

### 核心特点
1) 走进一部"活的漫画" 在高对比的墨线风格世界中前进；层层叠叠的 2D 分镜彼此渗透、交错，形成独特的空间与动线体验。
2) 次元间的视角切换 在"远距离、带窥视感的点按观察者视角"和"第一人称"之间无缝过渡；你会进入那缕灵魂的视角，穿行在像纸张分镜之间。
3) 寻找最后的安眠 一段紧凑的约 3 分钟存在主义旅程，适合在一次安静的独处时间里完整体验。

### 设计思路
设计起因与体验目标 未眠 最初是一个关于梦游者的实验：一段短篇互动能不能让玩家像"走进漫画分镜"——在 2D 与 3D 之间漂移，仿佛整张纸页本身就是可导航的世界？我想把"转场"当成叙事意义，而不只是视觉噱头：维度切换用来表达记忆的断裂与情感距离。

我围绕"分镜"来搭建体验。每一个"分镜"既是画面构成，也是流程导航：你互动的东西，是你能到达的地方。根据体验目标倒推（安静、悬浮、略带不真实），把节奏拆成循环：进入分镜 → 阅读空间 → 跨过边界 → 回到同一瞬间的另一种理解。整个设计需要确保可读性：就算世界发生切换，玩家也应该始终知道下一步该往哪走。
